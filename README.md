# 🛒 AI-Powered E-Commerce Platform

An AI-powered full-stack e-commerce platform built using the MERN stack. The application provides a modern online shopping experience with secure authentication, product management, shopping cart, order management, and an AI-powered shopping assistant.

---

## 🚀 Features

### 👤 User Features

* User Registration and Login
* Google Authentication
* Secure JWT Authentication
* Browse Products
* Search Products
* Product Categories
* Product Details Page
* Add to Cart
* Update Cart Quantity
* Place Orders
* View Order History
* Responsive User Interface
* AI Shopping Assistant

### 🛠️ Admin Features

* Secure Admin Login
* Add New Products
* Upload Product Images
* View All Products
* Manage Product Listings
* View Customer Orders
* Update Order Status

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Santanu-max/AI-Powered-E-Commerce-Platform.git
```

### 2. Open the project

```bash
cd AI-Powered-E-Commerce-Platform
```

---

## 📦 Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd ../frontend
npm install
```

### Admin

```bash
cd ../admin
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd backend
npm run dev
```

### Start Frontend

```bash
cd frontend
npm run dev
```

### Start Admin Panel

```bash
cd admin
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the `backend` folder and configure the required environment variables.

Example:

```env
PORT=8000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

> Never commit your `.env` file to GitHub.
